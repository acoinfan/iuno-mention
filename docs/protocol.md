# iuno-mention 协议 1

客户端（查看器，或者别的程序）用登记过的 SSH 钥匙连 remote，强制命令跑中转；stdin、stdout 上一行一个 JSON（UTF-8）。

## 握手

| 方向 | 内容 |
| --- | --- |
| 客户端 → 中转 | `{"op":"hello","proto":1}` |
| 中转 → 客户端 | `{"op":"hello","proto":1,"client":"iuno-pc-viewer"}`（名字由强制命令给，客户端改不了） |
| 版本对不上 | `{"op":"error","why":"…"}`，然后断开 |

## 之后

| 方向 | 内容 |
| --- | --- |
| 客户端 → 中转 | `{"op":"send","id":12,"title":"会话标题","text":"正文","urgent":false,"link":"可选"}` |
| 中转 → 客户端 | `{"op":"ack","id":12,"status":"queued"}`；插件暂停着时 `status` 是 `paused`，这封没收，客户端自己存着，恢复后再发 |
| 中转 → 客户端 | 每 5 秒 `{"op":"alive","paused":false}`，15 秒收不到算断了 |
| 中转 → 客户端 | `{"op":"reply","id":12,"text":"主人的回复","at":时刻,"from":"QQ 号的哈希"}` |

- `id` 是客户端自己的编号，原样带回来。QQ 上显示的 `#编号` 由插件给，几台机器不会撞；48 小时后作废，每个编号只收一次回复。
- 只往后加字段。要改已有字段就升 `proto`，客户端同时认新旧两版、过渡一个版本。

## 把关

发多少、什么时候发由客户端管（查看器的限流、静默时段）。插件只兜底：每个客户端一小时最多 30 条，多的丢弃并记日志。
